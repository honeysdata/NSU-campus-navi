3. 3주 프로젝트 계획WEEKLY PLAN
WEEK 01
고정 폭 Mask 파일럿
남서울대 일부 영역에서 파이프라인의 첫 실행을 검증합니다.
  1. OSM/JOSM 중심선과 항공영상 매칭
  2. 고정 폭 Buffer Mask 생성
  3. U-Net + MobileNetV3 1차 학습
  4. Ground Truth·Prediction Overlay 비교
  5. Dice·IoU·학습 시간 기록
산출물: 1차 Mask · 모델 · 전후 예측
WEEK 02
Overlay 검수·라벨 고도화
모델보다 중요한 GT Mask 품질을 개선합니다.
  1. 항공영상·라벨·예측 Overlay 확인
  2. 누락 보행로 추가·오인식 영역 삭제
  3. 보행로 종류별 폭 기준 정의
  4. 검수 GeoJSON 저장
  5. 검수 전후 Mask 차이 확인
산출물: 검수 라벨 · Buffer 기준 · 개선 Mask
WEEK 03
최종 학습·Graph 진입 판단
고도화된 라벨로 재학습하고 다음 단계를 결정합니다.
  1. 검수 GeoJSON → 실제 폭 Buffer → 최종 Mask
  2. U-Net + MobileNetV3 재학습
  3. 끊김·광장 오인식·연결성 평가
  4. 양호하면 Skeleton → Node·Edge → PostGIS
  5. 부족하면 DeepLabV3 + MobileNetV3 비교
산출물: 최종 모델 · Graph · 경로 검증
